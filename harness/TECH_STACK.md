## Core
- **Frontend**: React 18, TypeScript, Vite
- **UI/Styling**: Tailwind CSS v4, Lucide React

## Data & Backend
- **State Management**: Redux Toolkit
- **Backend/Auth**: Supabase (Database, Auth, Edge Functions)
- **AI**: Google Gemini API
- **Storage**: Chrome Storage API, Local Storage

## Tools & Performance
- **Build**: Vite (Code Splitting, manualChunks)
- **Animation**: framer-motion
- **Drag & Drop**: @dnd-kit
- **Visualization**: chart.js
- **Loading UI**: Typewriter-effect
