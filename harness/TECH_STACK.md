## Core
- **Frontend**: React 18, TypeScript, Vite
- **UI/Styling**: Tailwind CSS v4, Lucide React

## Data & Backend
- **State Management**: Redux Toolkit
- **Backend/Auth**: Supabase (Database, Auth, Edge Functions)
- **AI**: Google Gemini API
- **Storage**: Chrome Storage API, Local Storage

## Tools & Performance
- **Build**: Vite (Code Splitting, manualChunks, Extension Build Script)
  - *현재: 수동 빌드 스크립트 방식의 확장 프로그램 아키텍처 적용*
  - *향후: 개발 편의성 극대화를 위해 전용 HMR 라이브러리 도입 및 빌드 자동화 파이프라인 고도화 예정*
- **Animation**: framer-motion
- **Drag & Drop**: @dnd-kit
- **Visualization**: chart.js
- **Loading UI**: Typewriter-effect
